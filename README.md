# 星光邮差 · Starlight Courier

驾驶纸飞机收集星光、躲避陨石的浏览器小游戏，支持电脑和手机。

[在线试玩](https://starlight-courier-game.tastyowl8.chatgpt.site/)

## 操作

- 电脑：左右方向键或 A / D 移动，P 暂停或继续。
- 手机：按住并拖动纸飞机。
- 连续收集星光提高倍率，月光信标补充一次机会。
- 最高分保存在当前浏览器本地。

## 本地运行

下载仓库后，在浏览器中打开 `index.html` 即可游玩，无需安装依赖。

游戏使用原生 HTML、CSS 和 JavaScript Canvas，所有代码都在 `index.html` 中。
